# TypeScript Roadmap

🇧🇷 **Português** | [🇺🇸 English](./README.en.md)

Este repositório reúne pequenos projetos e exercícios desenvolvidos ao longo dos meus estudos, seguindo o [TypeScript Roadmap do roadmap.sh](https://roadmap.sh/typescript).

Cada diretório representa um macrotema do roadmap, com o objetivo de transformar o conhecimento teórico adquirido em implementações práticas que explorem seus tópicos e subtópicos.

O conteúdo teórico foi estudado com o auxílio do ChatGPT. Todo o código deste repositório foi escrito manualmente, sem geração por IA ou agentes de programação, sendo posteriormente submetido a revisões e discussões técnicas com o modelo.

### Observações

Os projetos têm caráter educacional e priorizam a aplicação dos fundamentos de cada macrotema. Por esse motivo, arquiteturas mais elaboradas, padrões de projeto e técnicas avançadas podem não estar presentes quando não fizerem parte do conteúdo estudado.

Esses conceitos serão incorporados progressivamente, conforme o avanço dos estudos.

## Projetos

| Tema | Descrição |
|---|---|
| [01 - Introduction to TypeScript](./01%20-%20Introduction%20to%20TypeScript/) | CRUD de usuários em memória para praticar fundamentos de TypeScript, configuração, compilação e interoperabilidade com JavaScript. |
| [02 - TypeScript Types](./02%20-%20TypeScript%20Types/) | Processador de pedidos com interfaces, Union Types, Type Narrowing, unknown, never, as const e satisfies. |
| [03 - Type Inference](./03%20-%20Type%20Inference/) | Um pequeno exercício para praticar inferência de tipos.|
| [04 - Type Compatibility](./04%20-%20Type%20Compatibility/) | Um pequeno exercício para praticar compatibilidade de tipos|
| [05 - Combining Types](./05%20-%20Combining%20Types/) | Gerenciador de chamados para praticar Union Types, Intersection Types, Type Aliases e o operador `keyof`. |
