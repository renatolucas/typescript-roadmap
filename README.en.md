# TypeScript Roadmap

[🇧🇷 Português](./README.md) | 🇺🇸 **English**

This repository contains small projects and exercises developed throughout my TypeScript learning journey, following the [TypeScript Roadmap by roadmap.sh](https://roadmap.sh/typescript).

Each directory represents a major roadmap topic, aiming to turn theoretical knowledge into practical implementations covering its topics and subtopics.

The theoretical content was studied with the assistance of ChatGPT. All code in this repository was written manually, without AI-generated code or coding agents, and subsequently reviewed and discussed with the model.

### Disclaimer

These projects are intended for educational purposes and focus on applying the fundamentals of each major topic. Therefore, more elaborate architectures, design patterns, and advanced techniques may not be included when they fall outside the scope of the concepts being studied.

These concepts will be progressively incorporated as my studies advance.

## Projects

| Topic | Description |
|---|---|
| [01 - Introduction to TypeScript](./01%20-%20Introduction%20to%20TypeScript/) | In-memory User CRUD exploring TypeScript fundamentals, configuration, compilation, and JavaScript interoperability. |
| [02 - TypeScript Types](./02%20-%20TypeScript%20Types/) | Order processing application exploring interfaces, union types, type narrowing, unknown, never, as const, and satisfies. |
| [03 - Type Inference](./03%20-%20Type%20Inference/) | A short exercise to practice Type Inference.|
| [04 - Type Compatibility](./04%20-%20Type%20Compatibility/) | A short exercise to practice Type Compability|
| [05 - Combining Types](./05%20-%20Combining%20Types/) | Ticket management project to practice Union Types, Intersection Types, Type Aliases, and the `keyof` operator. |
